# FestEngine и приложение: памятка оператору

FestEngine сам сообщает приложению, что происходит на сцене. Отдельно отмечать
это в приложении не нужно.

| Что делаете в FestEngine       | Что видят зрители в приложении                            |
| ------------------------------ | --------------------------------------------------------- |
| F1 или F2 на номере            | Номер становится текущим, подписчики получают уведомление |
| Пишете в заметке `пропуск`     | Номер пропущен                                            |
| Стираете `пропуск` из заметки  | Номер снова в программе                                   |
| Пишете в заметке `>NNN`        | Номер переезжает после номера NNN                         |
| Удаляете строку-дубль (`200a`) | Номер возвращается на прежнее место                       |

Перед фестивалем:

- **Сверьте часы ноутбука.** Если они расходятся больше чем на 5 минут,
  приложение отклоняет события.
- **Нажмите «Send test event».** Должен прийти ответ `200`.
- **Держите «Send Webhooks» выключенным на репетициях** и включайте перед
  первым номером.

Если номер сменился в FestEngine, а в приложении нет:

- **Подождите.** Между уведомлениями есть пауза, FestEngine повторит
  отправку сам.
- **Проверьте строку статуса.** Поле `Hook` показывает ответ приложения.
