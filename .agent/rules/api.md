## Single Source of Truth

- Always use the generated types from @/src/lib/api/v1.d.ts.
- Never define new TypeScript interface or type objects from scratch for API-related data.
- For type hinting, create type alises using the components["schemas"] lookup pattern under @/src/lib/types directory
  Example: type UserFullDTO = components["schemas"]["UserFullDTO"];

## Client Usage (openapi-fetch)

openapi-fetch is a type-safe fetch client that pulls in OpenAPI schema.

- Use the shared client from @/src/lib/index.ts.
- GET(), PUT(), POST(), etc. are thin wrappers around the native fetch API (which you can swap for any call).
- SvelteKit SSR: Inside load functions or hooks.server.ts, you must pass the Svelte-provided fetch to the client options to prevent hydration mismatches and handle relative URLs.
- Error Handling: Always check and log errors before accessing data.

### Basic usage

1. The HTTP method is pulled directly from client.
2. You pass in your desired path to GET(), PUT(), etc.
3. TypeScript takes over the rest and returns helpful errors for anything missing or invalid

### Request

The GET() request shown needed the params object that groups parameters by type (path or query). If a required param is missing, or the wrong type, a type error will be thrown.
The POST() request required a body object that provided all necessary requestBody data.

### Response

All methods return an object with data, error, and response.

- data - 2xx response if OK; otherwise undefined;
- error - 5xx, 4xx, or default response if not OK; otherwise undefined;
- response - The original Response which contains status, headers, etc.;

Every API request must use the following destructuring pattern for the return object:
const { data, error, response } = await client.GET("/url");

### Middleware

Each middleware can provide onRequest(), onResponse() and onError callbacks, which can observe and/or mutate requests, responses and fetch errors.

import createClient, { Middleware } from "openapi-fetch";
import type { paths } from "./my-openapi-3-schema"; // generated by openapi-typescript

const myMiddleware: Middleware = {
async onRequest({ request, options }) {
// set "foo" header
request.headers.set("foo", "bar");
return request;
},
async onResponse({ request, response, options }) {
const { body, ...resOptions } = response;
// change status of response
return new Response(body, { ...resOptions, status: 200 });
},
async onError({ error }) {
// wrap errors thrown by fetch
return new Error("Oops, fetch failed", { cause: error });
},
};

const client = createClient<paths>({ baseUrl: "https://myapi.dev/v1/" });

// register middleware
client.use(myMiddleware);
