# Curated Russian profanity (mat) roots for substring matching.
#
# Each non-empty, non-comment line is a root. After normalization (see
# adapters/profanity/filter.py) a username is flagged when it CONTAINS any of
# these roots as a substring. Roots are chosen to be unambiguous: they must not
# appear inside ordinary Russian words, so the substring match stays precise.
# Lines are normalized the same way as input, so write them in plain Cyrillic.
