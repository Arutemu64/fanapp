## Conflicts with project direction (R-37: owner decides, not auto-fixed)

- **R-02 em dash vs Russian punctuation.** `ru.json` has 31 strings with ` —`. In Russian the тире is grammatical (it replaces a copula or joins clauses), so swapping it for a comma or colon would change the grammar, and redpolitika.md and `fanfan-russian-copy` govern copy here. Event titles shaped like "Персонаж — Фэндом" are data, not copy. **Recommendation: keep it and record this as an override.**
- **antislop-layoutmobile "fluid type (`clamp()`)" vs DESIGN.md's Fixed-Scale Rule.** DESIGN.md is the direction here, so keep fixed rem steps.
- **The antislop pointer block in `AGENTS.md`/`CLAUDE.md`.** The skill's install wizard wants a block that asks the during/after mode question every session. It was not added, because Claude Code already loads the skills by their descriptions and the repo routes skills through the AGENTS.md "Load before you edit" table. Add a row there if you want antislop tied to UI work.
